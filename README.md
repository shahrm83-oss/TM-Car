# Terrier Motorsport Car
The design process for the onboarding project for Terrier Motorsport. This was a battery-powered real wheel motor car.

## What I did
It was a 10 week long process while involved designing the car using the constraints provided, planning the manufacturing process and then manfucaturing it using materials provided.

## Tools
Fusion 360 · CNC Mill · Manual Lathe · Lazer cutter · 3D Printer
